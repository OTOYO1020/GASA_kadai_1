# ことのは — ブラウザ日本語入力

外部通信・外部ライブラリ不要の、日本語入力デモです。

## 起動

```sh
cd /workspace/GASA_kadai_1
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザで `http://localhost:8000` を開きます。
端末の入力モードを半角英数にし、下の入力欄へローマ字を入力します。
Enter でかなを確定、Space で候補を選択し Enter で確定できます。
候補クリックでも確定できます。確定済みテキストは上の欄で編集できます。

`nn`、`n'`、促音、拗音、小書き文字、カタカナ変換に対応します。
漢字変換は内蔵単語辞書の完全一致のみです。文章の分かち書きや学習はありません。
文章はメモリ上にのみ保持し、再読み込みで消えます。

## 検証

```sh
node --test ime.test.js
```

## 日本語教育向けの練習

初級者向けに、ひらがなの基本・小さい文字と「ん」・カタカナの3コース（各5問）を用意しています。
お手本と英語の意味を見てローマ字で入力し、「たしかめる」でかなの一致を確認できます。
ヒント、46文字のかな・入力対応表、授業での使い方も表示できます。
正解数はコース内の正解済み問題数です。同じ問題の重複正解では増えず、コース変更・再読み込みでリセットします。
発音や筆順の評価、学習記録の永続保存はありません。
